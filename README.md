# Eclaire on Railway

A one-click [Railway](https://railway.com) template for [Eclaire](https://github.com/eclaire-labs/eclaire), the open-source (MIT) AI assistant for your tasks, notes, documents, photos and bookmarks.

**Version:** Eclaire v0.6.3, official image `ghcr.io/eclaire-labs/eclaire:0.6.3`, pinned by digest in the [`Dockerfile`](Dockerfile).

## What it deploys

| Service | What it does | Storage |
| --- | --- | --- |
| **Eclaire** | Web app, API, background workers and scheduler in one process (built from this repo) | Volume at `/app/data` (uploaded files, photos, thumbnails, browser cache) |
| **Postgres** | Railway Postgres: all records, users, sessions and the job queue | Volume (Railway Postgres) |

## Variables

| Variable | Default | What it is |
| --- | --- | --- |
| `LLM_API_KEY` | *(you enter it)* | API key for your OpenAI-compatible AI provider. The only value you must supply. |
| `LLM_BASE_URL` | `https://api.openai.com/v1` | Provider base URL. For OpenRouter use `https://openrouter.ai/api/v1`; any OpenAI-compatible endpoint works. |
| `LLM_MODEL` | `gpt-4o-mini` | Model name at that provider. It should support tool calls and, for photos, images. |
| `ADMIN_EMAIL` | `admin@eclaire.local` | Email of the admin account created on first boot. |
| `ADMIN_PASSWORD` | generated | Admin password, generated by Railway. Find it in the Eclaire service's Variables tab. |
| `BETTER_AUTH_SECRET`, `MASTER_ENCRYPTION_KEY`, `API_KEY_HMAC_KEY_V1` | generated | Session, encryption and API-key secrets. Never change them after the first deploy. |
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` | Private connection to the Postgres service. |
| `FRONTEND_URL` | `https://${{RAILWAY_PUBLIC_DOMAIN}}` | Public URL, used for trusted origins. |

Optional, not set by the template: `LLM_VISION=false` (text-only model), `LLM_CONTEXT_WINDOW` (default 128000), `DOCLING_SERVER_URL` (a [Docling Serve](https://github.com/docling-project/docling-serve) service for better PDF and image extraction), `WORKER_CONCURRENCY`, `GITHUB_TOKEN` and `REDDIT_CLIENT_ID`/`REDDIT_CLIENT_SECRET` (richer bookmark processing).

## What this wrapper changes

- **Login is locked on the first deploy.** Upstream lets anyone sign up. Here the start script creates your admin account on a loopback-only port, then starts the public server with email sign-up switched off. Set `ECLAIRE_ALLOW_SIGNUP=true` only if you want to let others register.
- **AI provider from variables.** Upstream expects local llama.cpp servers. The start script writes `config/ai/*.json` for one OpenAI-compatible endpoint, so a key is all you need. Change the model by editing `LLM_MODEL` and redeploying.
- **Docling is optional.** Without `DOCLING_SERVER_URL`, PDFs use `pdftotext` and Office files use LibreOffice, both inside the image.
- **Sized to the service.** Node heap, worker concurrency, image threads and the Postgres pool follow the service's memory and CPU limits.
- **Safe migrations.** Database upgrades run on start under a Postgres advisory lock, so overlapping deploys never migrate twice. A failed start exits non-zero so Railway restarts it.

## Resources

Eclaire's image is about 2 GB (it bundles LibreOffice and Chromium for documents and bookmarks). It runs within Railway's Free plan limit of 0.5 GB per service for normal use, but processing large documents or web pages with Chromium works best with 1 GB or more (Hobby plan). Railway's Free plan allows one volume per project, and this template needs two (Postgres and Eclaire's files), so use the Trial, Hobby or a higher plan.

## Security

Eclaire's authors say it is not hardened for direct exposure to the internet. This template keeps its login on, closes sign-up and generates every secret, but it is still a public URL. Use a strong admin password, and consider Railway's private networking or a VPN-style access layer if you keep sensitive data in it.

## Updates

Railway notifies you when this repo's `main` branch changes. Read [`CHANGELOG.md`](CHANGELOG.md), then apply the update from your project. Database upgrades run on start. Eclaire is pre-release software: back up your Postgres data before applying a new version.
